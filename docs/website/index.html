Built around the film stack

Every layer knows what it is

Print order, not layer numbers

Up to 64 GDSII layers, each given a role: conductor, dielectric, resistor ink, glaze, epoxy, die pads, wire bonds. Top views, 3D models and thermal analysis all stack them as they are fired.

Printed resistors from value and power

The Resistor Designer sizes each resistor from value, tolerance, power and ink, and the trim simulator models plunge and L-cut laser trimming.

Dielectric generated, not drawn

After routing, the dielectric sheet is rebuilt inside the I/O ring with a window at every via.

Key features

The tools a hybrid needs, in one editor

ROUTE

Autorouting with Freerouting

Your DRC rules set the widths and clearance. Wire-bond landings become bond fingers. The ALU16 chip-and-wire build routes 85 of 85 nets.

BOND

Chip-and-wire router

Single-conductor hybrids routed with wire-bond jumpers, plus a bond diagram CSV in bonding order for the wire bonder.

PLACE

Auto Place

Shortest weighted net length with power and ground counted, hot parts kept apart, and straight-line interconnects that follow every drag.

CHECK

DRC and netlist extraction

Widths, spacings, substrate-edge clearance and wire-bond length and angle, then copper connectivity compared against your nets.

HEAT

Thermal, resistor shapes and trim

Die and resistor temperatures against their limits; top-hat, U and angle resistors sized from their real outline; plunge and L-cut trims step by step. See the tools

CAM

Manufacturing outputs

Gerber per print layer, DXF, pick-and-place centroids, test netlists and a one-step assembly drawing with pin, resistor and bond tables.

Example 5 · ALU8 chip and wire

One design, from layout to 3D

An 8-bit ALU built from six bare dies (two 54AS181 ALU slices and four 54LS gates) wire-bonded onto a two-conductor thick-film substrate, sealed in a 40-pin Kovar DIP package. 46 nets, placed by Auto Place from the netlist and routed with Freerouting.

3D and documentation

Export the design to FreeCAD as one solid per film at its fired thickness, with real STEP bodies for chip capacitors, SOT and LCC packages, Kovar headers and bare dies. The SolidCraft view writes STEP, 3MF, STL or OBJ.

Questions

Thick-film hybrid layout, answered

What is HLayout?

HLayout is free, open-source layout CAD for thick-film hybrid circuits and chip-and-wire microelectronic modules. It draws the printed conductors, dielectric, resistor inks and glaze on a ceramic substrate, places packaged parts and bare dies, routes them, checks the design and writes the manufacturing files.

What is a thick-film hybrid circuit?

A thick-film hybrid is a circuit whose conductors, insulating dielectric and resistors are screen-printed as pastes on a ceramic substrate, usually alumina, and fired. Chip components, packaged parts and bare semiconductor dies are then attached; bare dies are connected with wire bonds, which is called chip-and-wire assembly.

Does HLayout work with KiCad?

Yes. Draw the schematic in KiCad and export the netlist; HLayout reads it, places the parts with Auto Place and routes with Freerouting through a Specctra DSN/SES round trip. Die pads and pins can be numbered or named, such as E, B and C for a transistor die.

Can HLayout design thick-film printed resistors?

Yes. The Resistor Designer sizes each resistor from its value, tolerance and power: it picks the body width for the power, an aim value below target for laser trimming, the ink and the number of squares, then places the ink, terminations, glaze and dielectric keep-out. Besides the rectangle it designs top-hat, top-hat with roof, U-shape, U-shape with roof, angle, double angle and angle three-sided resistors, sized by solving their ink as a resistive sheet. A trim simulator shows plunge and L-cut trims.

Which manufacturing outputs does it produce?

Gerber RS-274X for every print layer, DXF, pick-and-place files, bond lists for the wire bonder, test netlists, an assembly drawing with title block and pin table, and a 3D model of the fired substrate and parts for FreeCAD with STEP models.

Does it check wire bonds and design rules?

Yes. Design rule checks cover track widths, spacing, substrate-edge clearance and wire-bond length and departure angle. Netlist extraction compares the drawn copper and bonds with the schematic, and a thermal analysis estimates die and resistor temperatures.

Is HLayout really free, and which systems does it run on?

HLayout is free software under the GNU GPL v3.0 or later, with the full source on GitHub. Installers are available for Windows, Linux (Debian/Ubuntu) and macOS, and it can also run from source with Python.

Is training or help available?

Yes. A three-day hands-on training course takes an 8-bit ALU chip-and-wire design from netlist to Gerbers and 3D, and process setup, part libraries, custom features, layout design and support are available from support@h-layout.co.uk.

Run from source

HLayout is a Python application. With Python 3.10 or later and Tkinter you can run it on any system, including Intel Macs and non-Debian Linux.

# Debian/Ubuntu only: sudo apt install python3-tk
git clone https://github.com/alvinmb/Hlayout.git
cd Hlayout
pip install -r requirements.txt
python hlayout_app.py hlayout/examples/notch_filter.gds

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Help → Report Bug saves its report on your computer and opens a GitHub issue only when you ask. The MCP bridge is off until you turn it on and listens only on this computer. Freerouting, installed separately, is run with its analytics turned off.

This website uses Google Analytics only if you accept analytics cookies. It counts page visits and downloads to show which pages are useful; it does not identify you and is not used for advertising. Without your consent no analytics cookies are set and nothing is sent to Google.
