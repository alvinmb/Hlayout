Thick-film hybrid layout CAD

Lay out hybrids, not PCBs.

HLayout designs the printed conductors, dielectric, resistor inks and glaze of a thick-film hybrid on its ceramic substrate, with packaged parts or wire-bonded bare dies. It takes a KiCad netlist in and sends Gerbers, bond diagrams, assembly drawings and 3D models out.

Built around the film stack

Every layer knows what it is

Print order, not layer numbers

Up to 64 GDSII layers, each given a role: conductor, dielectric, resistor ink, glaze, epoxy, die pads, wire bonds. Top views, 3D models and thermal analysis all stack them as they are fired.

Printed resistors from value and power

The Resistor Designer sizes each resistor from value, tolerance, power and ink, and the trim simulator models plunge and L-cut laser trimming.

Dielectric generated, not drawn

After routing, the dielectric sheet is rebuilt inside the I/O ring with a window at every via.

Key features

The tools a hybrid needs, in one editor

ROUTE

Autorouting with Freerouting

Your DRC rules set the widths and clearance. Wire-bond landings become bond fingers. The ALU16 chip-and-wire build routes 85 of 85 nets.

BOND

Chip-and-wire router

Single-conductor hybrids routed with wire-bond jumpers, plus a bond diagram CSV in bonding order for the wire bonder.

PLACE

Auto Place

Shortest weighted net length with power and ground counted, hot parts kept apart, and straight-line interconnects that follow every drag.

CHECK

DRC and netlist extraction

Widths, spacings, substrate-edge clearance and wire-bond length and angle, then copper connectivity compared against your nets.

HEAT

Thermal analysis

Steady-state conduction through substrate and films gives each resistor, die and part a temperature against its limit.

CAM

Manufacturing outputs

Gerber per print layer, DXF, pick-and-place centroids, test netlists and a one-step assembly drawing with pin, resistor and bond tables.

Example 5 · ALU8 chip and wire

One design, from layout to 3D

An 8-bit ALU built from six bare dies (two 54AS181 ALU slices and four 54LS gates) wire-bonded onto a two-conductor thick-film substrate, sealed in a 40-pin Kovar DIP package. 46 nets, placed by Auto Place from the netlist and routed with Freerouting.

3D and documentation

See it fired before it is printed

Export the design to FreeCAD as one solid per film at its fired thickness, with real STEP bodies for chip capacitors, SOT and LCC packages, Kovar headers and bare dies. The SolidCraft view writes STEP, 3MF, STL or OBJ.

Any platform

Run from source

HLayout is a Python application. With Python 3.10 or later and Tkinter you can run it on any system, including Intel Macs and non-Debian Linux.

# Debian/Ubuntu only: sudo apt install python3-tk
git clone https://github.com/alvinmb/Hlayout.git
cd Hlayout
pip install -r requirements.txt
python hlayout_app.py hlayout/examples/notch_filter.gds

Licence and policies

Free software you can inspect

Licence

HLayout is free software under the GNU General Public License v3.0 or later: you can use, study, change and share it, and the full source is on GitHub. The chip-and-wire router is a fork of Freerouting, also GPL-3.0.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Signing starts with the first release after the project is accepted; earlier installers are unsigned.

Committers and reviewers: Alvin Brown. Approvers: Alvin Brown. Only release builds made by the project's GitHub Actions workflow from its public source are signed, and each request is approved by hand.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Help → Report Bug saves its report on your computer and opens a GitHub issue only when you ask. The MCP bridge is off until you turn it on and listens only on this computer. Freerouting, installed separately, is run with its analytics turned off.

Uninstalling

Windows: Settings → Apps, or Uninstall HLayout in the Start menu. Debian/Ubuntu: sudo apt remove hlayout. macOS: drag HLayout from Applications to the Bin.
