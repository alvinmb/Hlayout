Why free

Hybrid layout without the licence bill

HLayout is free, open-source layout software made for thick-film hybrid circuits and chip-and-wire modules, not a PCB tool stretched to fit.

FREE

No fees, no seats

Download it, install it on every designer's machine, use it for commercial work. Nothing to buy, renew or activate.

OPEN

Read and change the code

The full source is on GitHub under GPL-3.0. Check how a rule is applied, fix what you need, or build your own tools on it.

PYTHON

Scriptable

Every tool has a Python call and a command, so a whole flow (read netlist, place, route, check, output) can run as a script.

OPEN FORMATS

Fits an open toolchain

KiCad netlists in; GDSII, Gerber RS-274X, DXF, Specctra DSN/SES, STEP and CSV out; FreeCAD for 3D.

PLATFORMS

Windows, Linux, macOS

Installers for all three, built from the public source by the project's CI.

HYBRID FIRST

Made for thick film

Conductors, dielectric, resistor inks, glaze, bare dies and wire bonds are built in, not bolted onto a PCB tool.

Questions

Free and open source, answered

Is HLayout really free?

Yes. HLayout is free to download and use, for any purpose including commercial work, with no licence fees, seats or dongles. It is released under the GNU General Public License v3.

What does GPL-3.0 let me do?

Use HLayout for any work, read its source code, change it and share your changes. If you distribute a modified HLayout, you pass on the same freedoms with its source.

Are my designs open source too?

No. The licence covers the HLayout program, not the designs you make with it. Your layouts, technology files and libraries are yours.

Who maintains it?

Alvin Brown develops HLayout in the open on GitHub, where releases, source and the issue tracker live. Paid consultancy and training fund further work.
