Current release All releases and notes
New in 0.9.1Auto Place now reports in full: every overlap with the move that clears it (one click to apply), and a Check Routability button that tells you in under a second which pads no track can reach and which parts wall them in, which crossings have no room for a crossover, and how much of the board's routing room the nets need. Bare dies are placed with room for their bond fingers, and printed resistors take only their real footprint.
New in 0.9One autorouter for chip-and-wire hybrids (Tools → Autoroute…): a gridless shape router that routes on exact geometry, crosses on one conductor with a short printed crossover over a local dielectric strip kept clear of resistors, and falls back to a wire-bond jumper. Die-bond fan-out, an edge I/O pad wizard, header pinout and a Read Netlist flow round it out.
New in 0.8Thick-film resistors beyond the rectangle: top-hat, top-hat with roof, U, U with roof, angle, double angle and three-sided angle, each sized by solving the ink as a resistive sheet and trimmed in its own simulator. Setup → Technology Properties → Resistor Shapes sets which shapes your process supports, and only those are offered.
New in 0.7Every cell carries a created and modified date and time, in your design and in attached libraries (Setup → Library Cells…). The Chip Wizard makes real, named pins (E, B for a transistor) and can make the die-attach pad the back contact, such as a collector, with a tab for the track. HLayout is open source under GPL-3.0, and there is a three-day ALU8 training course.
New in 0.6Help → Report Bug collects versions, errors and recent steps into one report you can preview before sending. When an unexpected error appears, HLayout offers to report it with the details filled in.

Any platform

Run from source

HLayout is a Python application. With Python 3.10 or later and Tkinter you can run it on any system, including Intel Macs and non-Debian Linux.

# Debian/Ubuntu only: sudo apt install python3-tk
git clone https://github.com/alvinmb/Hlayout.git
cd Hlayout
pip install -r requirements.txt
python hlayout_app.py hlayout/examples/notch_filter.gds

Tools that plug into the workflow

HLayout runs on its own. These free tools add schematic capture, autorouting and 3D; install the ones you need.

Licence and policies

Free software you can inspect

Licence

HLayout is free software under the GNU General Public License v3.0 or later: you can use, study, change and share it, and the full source is on GitHub. The chip-and-wire router is a fork of Freerouting, also GPL-3.0.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Signing starts with the first release after the project is accepted; earlier installers are unsigned.

Committers and reviewers: Alvin Brown. Approvers: Alvin Brown. Only release builds made by the project's GitHub Actions workflow from its public source are signed, and each request is approved by hand.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Help → Report Bug saves its report on your computer and opens a GitHub issue only when you ask. The MCP bridge is off until you turn it on and listens only on this computer. Freerouting, installed separately, is run with its analytics turned off.

This website uses Google Analytics only if you accept analytics cookies. It counts page visits and downloads to show which pages are useful; it does not identify you and is not used for advertising. Without your consent no analytics cookies are set and nothing is sent to Google.

Uninstalling

Windows: Settings → Apps, or Uninstall HLayout in the Start menu. Debian/Ubuntu: sudo apt remove hlayout. macOS: drag HLayout from Applications to the Bin.
