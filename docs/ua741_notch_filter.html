Twin-T notch filter — µA741

A twin-T RC network placed ahead of a µA741 voltage follower. The network nulls one frequency; the op-amp buffers it and, in the adjustable-Q version, bootstraps the null to sharpen it.

Design equations

f0 = 1 / (2π R C)notch (null) frequency
R1 = R2 = R  ·  C1 = C2 = Cthe two series arms
C3 = 2C  ·  R3 = R / 2the two shunt legs
Q ≈ 0.25passive twin-T, buffered only
Q = 1 / [ 4 (1 − k) ]shunt legs bootstrapped by k·Vout
notch depthset by component match, not by Q

Pick C first (a value you can buy in 1 % or better), then solve R = 1 / (2π f0 C). The shunt leg R/2 and 2C must track the arms to ~0.1 % for a deep null — use two R in parallel for R/2 and two C in parallel for 2C so every element is the same part.

Adjustable-Q (bootstrapped) variant

Instead of grounding C3 and R3, tie both to the wiper of a divider across the output — a fixed resistor to ground plus a pot to Vout, giving feedback fraction k (0 to <1). Positive feedback around the twin-T raises Q to 1 / [4(1 − k)]: k = 0 gives Q = 0.25, k = 0.9 gives Q = 2.5, k = 0.95 gives Q = 5. A second µA741 as an input buffer keeps the source impedance from detuning the network. Keep k below ~0.97 — the loop peaks and rings as it approaches oscillation.

NoteThe bootstrap moves the notch slightly and interacts with component tolerance. Set f0 with the pot at minimum Q, then raise Q and re-check the null.

Build notes

  • Supplies. Dual rail, ±5 to ±18 V (±15 V typical). Decouple pins 7 and 4 with 100 nF to ground at the socket.
  • Component match. Null depth is set by how well R/2 and 2C track R and C. Use 1 % metal-film resistors and 1 % (C0G/NP0 or film) capacitors; parallel identical parts for the shunt legs.
  • Source and load. Drive the twin-T from a low impedance (buffer the source) and take the output from the op-amp, which presents a high-impedance input to node A.
  • µA741 limits. GBW ≈ 1 MHz, slew rate 0.5 V/µs — fine for mains-hum and audio notches, not for RF. Offset-null pins 1 and 5 (10 kΩ pot wiper to V−) if DC offset at the output matters.
  • Verify on the bench. Sweep the input and confirm the null frequency and depth; twin-T circuits are sensitive enough that calculated values always need a trim.
